Tailstech's World

A heavily modded world built around exploration, engineering, long-distance travel and enormous landscapes.

Download the modpack Installation

Built for one persistent world

Tailstech's World is designed around a long-running multiplayer world where distance matters. Build railways, roads and other infrastructure, explore vast terrain, and solve problems using the systems available to you rather than simply skipping them with cheap fast travel.

Huge landscapes

Distant Horizons is built into the experience so mountains, coastlines and distant terrain remain part of the world instead of disappearing a few chunks away.

Engineering & transport

Trains, aircraft, boats, roads and other systems make getting somewhere part of the adventure.

Exploration with purpose

Progression encourages expeditions into increasingly dangerous and unusual environments without turning every encounter into a mandatory boss gate.

INSTALLATION

Get into the world

  1. Install the CurseForge launcher.
  2. Download the Tailstech's World profile.
  3. In CurseForge, choose Import and select the downloaded ZIP.
  4. Launch the imported profile.
  5. Open Multiplayer. The Tailstech's World server is already included.
